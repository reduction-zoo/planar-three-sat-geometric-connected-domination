# Working proof of the composed reduction

Status: **candidate argument, not yet a complete accepted proof**. The mathematical chain below identifies the needed lemmas. The executable orthogonal drawing implementation still needs a totality and worst-case-size audit on this generated graph family; target NO instances have not been independently solved.

## Contract and maps

The source and target encodings are fixed in [contract.md](contract.md). For an empty formula with zero variables, `F` emits one integer point with `K=1`, and `G` returns the empty assignment from a target witness. All other legal inputs use the chain below. If the target output is `NO-SOLUTION`, `G` returns `NO-SOLUTION`; otherwise it reconstructs the same deterministic point set, normalizes the selected grid vertices and reads a source assignment. The generated target has distinct integer points and nonnegative integer `K`.

## Embedded planar SAT to planar vertex cover

This stage is based on Lichtenstein, [*Planar formulae and their uses* (1982), §4, Theorem 3](https://www.math.ucdavis.edu/~deloera/MISC/LA-BIBLIO/trunk/Lichtens.pdf). For each variable, take a cycle of length `2 max(2, d)`, where `d` is its number of literal occurrences, with alternating true and false parity. Attach each occurrence to a distinct vertex of its literal's parity, in the incidence rotation order. For each clause, make a triangle and attach its three vertices to its literal ports. Repeated occurrences through one incidence edge fan out in opposite order at the variable and clause ends, preserving planarity. Every node has degree at most three. Let `B` be the sum of half-cycle lengths plus twice the number of clauses.

A satisfying assignment selects its parity on each variable cycle and two vertices of each clause triangle, omitting a true literal's vertex. This is a vertex cover of size `B`. Conversely, every cover of size at most `B` must use exactly half of each variable cycle and exactly two vertices of each triangle. A minimum cover of an even cycle selects one alternating parity, so the omitted triangle vertex has its incident literal port selected. Each clause therefore has a true literal in the extracted assignment. Isolated variables are handled by their four-cycles, and repeated literals have distinct ports.

## Planar cover to connected planar cover

This stage follows Garey and Johnson, [*The rectilinear Steiner tree problem is NP-complete* (1977), Lemma 2](https://www.math.ucdavis.edu/~deloera/MISC/LA-BIBLIO/trunk/JohnsonDavid1.pdf). Subdivide every edge `u-v` into `u-a-b-v`. On each planar face, attach a vertex `w'` and its pendant `w''` to each boundary vertex whose current degree is below four, and join the face's `w'` vertices cyclically. Components may be drawn in disjoint disks with their chosen outer faces merged into one exterior face cycle. Let `r` be the number of `w'` vertices and `e` the number of pre-subdivision edges. The connected-cover budget is `B'=B+e+r`. The generated graph is connected, planar and has maximum degree four.

From a planar cover, choose exactly one of `a,b` on every subdivided edge as in the cited proof and all `w'` vertices; the result is a connected cover of size `B'`. Conversely, every connected cover of size at most `B'` contains every `w'`: its pendant neighbor and the cover's connectedness force it. Every subdivided edge contains at least one of `a,b`; when neither original endpoint is selected, both are forced. Retain selected original vertices and add one endpoint of each such double-subdivider edge. This is a planar cover of size at most `B'−r−e=B`. This direct extraction also handles extra selected pendant vertices.

## Connected cover to integer-grid connected domination

Clark, Colbourn and Johnson, [*Unit disk graphs* (1990), §6, Theorem 6.1 and Lemmas 6.1–6.2](https://cs.du.edu/~snarayan/sada/research/docs/res/unitdisk.pdf), give this stage for connected planar degree-four graphs. Draw the core without its original pendant vertices orthogonally on an integer grid, then scale by ten. Reinsert each pendant original vertex four steps from its neighbor in an unused compass direction. Insert every intermediate integer point on each edge path. Call original graph vertices `V1`, all interior path points `V2`, and the first and last interior points on each path *connectors*. Place one further grid point beside each nonconnector in `V2`; these form `V3`.

The construction checks that no two main paths have unintended unit adjacency; every `V3` point has exactly one neighbor in `V2`, no neighbor in `V1` or a connector, and at most two neighboring `V3` points, each on an adjacent pair of the same edge path. The scale ten separation gives these properties if the unscaled orthogonal drawing is valid. Integer points are adjacent at Euclidean distance at most one precisely when their Manhattan distance is one. Let `N2=|V2|`, `N1=|V1|`, and `e'=|E(H)|` for the connected-cover graph `H`. Set `K=B'+N2−e'+N1−1`.

From a connected cover `C` of `H`, choose a spanning tree of `H[C]`, then attach every omitted vertex as a leaf through an edge to `C`. Select all nonconnector `V2` points, the `V1` points for `C`, both connectors on tree edges, and one connector incident to `C` on each other edge. This gives a connected dominating set of exactly `|C|+N2−e'+N1−1≤K` points.

For any target connected dominating set `D` of size at most `K`, normalize selected `V3` points by the constructive transformations in Clark et al. Lemma 6.1. If every middle pair on an edge contains its path or side point, replace its selected side points by path points. Otherwise a missing pair's side point is dominated by a selected neighboring side point. Follow the selected path to an endpoint, replace side points on that prefix or suffix by path points, and also select the missing pair's path point. The proof gives a replacement of no greater cardinality. The implementation enumerates the finitely many candidate intervals and checks domination and connectivity before accepting; every accepted step reduces the number of selected side points. Once `V3` is absent, the cited Lemma 6.2 implies that the selected original `V1` vertices form a connected vertex cover `C`. Each edge requires its middle points and at least one connector adjacent to a selected endpoint; each omitted original vertex needs a second connector on one incident edge, while connecting `C` needs at least `|C|−1` double-connector edges. Counting gives `|D|≥|C|+N2−e'+N1−1`, so `|C|≤B'`. The two earlier extraction steps return a satisfying assignment.

Thus a source assignment exists exactly when a target connected dominating set of size at most `K` exists, and every valid target witness can be decoded. The `NO-SOLUTION` branch follows the same equivalence.

## Size and unresolved implementation audit

The first graph has `O(n+m+sum d)` vertices and edges, with `sum d=3m`; isolated variables still contribute four vertices. The face construction remains linear in that graph's size. A polynomial orthogonal drawing with polynomial integer grid area is known for degree-four planar graphs; a valid such drawing would yield polynomially many output points and `O(log poly(|x|))` coordinate bits after fixed scaling. Recovery reconstructs the drawing, then uses polynomial-size graph checks and at most `|V3|` local normalization steps. These are polynomial assuming the drawing implementation always returns a valid polynomial-size layout on the generated core family.

`algorithm.py` currently calls `tsmpy` 0.9.3 and validates its result. All 111 prepared nonempty cores passed, but its documented overlay and cut-edge limitations leave the all-input implementation guarantee open. The proof above is therefore conditional at that interface. The present target oracle also could not complete the full prepared suite at the tested scale; see the later verification record. These are separate from the combinatorial equivalence claim.
